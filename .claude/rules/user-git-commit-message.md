# gitのコミットメッセージルール

- 機能変更をしたコミットの場合
  - `[modify]` のprefixをつける.
- 機能追加を行ったコミットの場合
  - `[add]` のprefixをつける.
- コミットメッセージの2行目に関連するチケット番号を記載する.
  - `refs #<num>` のように記載する.
- コミットメッセージの末尾に`Generated with Claude Code` やチャットURLは**記載してはいけない**.
- コミットメッセージの末尾に`Co-Authored-By` なども**記載してはいけない**.
- `Co-Authored-By: Claude`、`Generated by`、その他 AI の関与を示すいかなる表記もコミットメッセージに記載してはいけない.
